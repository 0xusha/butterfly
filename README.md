# Pygame 3D Butterfly Tunnel

A cinematic, infinite 3D butterfly tunnel built entirely in Python using Pygame. The animation features a sequential build phase that traces butterflies into nested heart shapes before diving into a high-speed, infinite 3D flight tunnel.

## Features

* **Procedural Sprites:** Generates high-definition, anti-aliased butterfly sprites dynamically.
* **Build Animation:** Sequentially draws nested heart shapes ring-by-ring.
* **3D Tunnel Flight:** Mathematical scaling and depth illusion for an infinite loop effect.
* **VFX:** Includes synthetic bloom/glow rendering and fading particle dust trails.

## Prerequisites

* Python 3.x
* Pygame
